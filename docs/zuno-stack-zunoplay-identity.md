# ZunoPlay identity in Stack

Zuno Stack uses the ZunoPlay dark-violet environment as its UI identity while reserving saturated family colors for playable pieces. The board includes a subtle Zuno Core `Z`, the title emphasizes Stack in violet, and utility chrome remains visually subordinate to the puzzle.

The reference-inspired improvement is structural readability only: stacked/staggered geometry, object-like tiles, blocked/free hierarchy, and a physical seven-slot tray. No third-party artwork, characters, assets, or branding are used.
