# Requisitos de deploy — Preview

O deploy válido precisa ser atribuível a um projeto Vercel ligado a `Samurayshon/ZunoPlay`, mostrar branch/commit implantado, expor URL acessível e disponibilizar logs.

A presença de `vercel.json` no repositório não é deploy. Uma URL não observada não é evidência. Um deploy que use Supabase de produção é falha do gate.
