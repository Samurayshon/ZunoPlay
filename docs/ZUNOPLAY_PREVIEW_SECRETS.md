# Secrets — Preview

Variáveis esperadas no host de Preview:

- `ZUNO_SUPABASE_URL`: URL do staging.
- `ZUNO_SUPABASE_PUBLISHABLE_KEY`: chave cliente publicável/anon-compatible do staging.

Nunca registrar valores de secret/service-role no GitHub, docs ou artefatos públicos. A chave cliente publicável pode ser entregue ao navegador, mas ainda deve pertencer ao projeto staging correto.
