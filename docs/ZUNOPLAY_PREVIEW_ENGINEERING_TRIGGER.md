# Gatilho para engenharia adicional

Se o inventário mostrar múltiplas inicializações Supabase incompatíveis, dependências circulares, necessidade de transformação de artefatos estáticos ou risco alto de regressão na autenticação, solicitar análise do Gemini com snapshot explicitamente confrontado contra a main.

Se a configuração puder ser centralizada com alteração pequena, testável e reversível, ChatGPT executa diretamente.
