# Zuno Stack — Biblioteca de Peças

Etapa 0B: biblioteca oficial expandida para 24 famílias visuais. Cada partida usa 6 famílias sorteadas do catálogo, mantendo 54 peças nesta etapa para não antecipar o aumento de tabuleiro previsto para a Etapa 0C.

Famílias: Bolt, Core, Nova, Prism, Orb, Echo, Vortex, Rune, Meteor, Crown, Portal, Crystal, Wave, Star, Moon, Rocket, Ghost, Clover, Pulse, Flux, Spark, Link, Comet e Shift.
